# Misha Evans — Personal Site

A static personal site: intro, social links, resume, and projects.
No build step — open `index.html` or deploy the folder anywhere static.

## Files
- `index.html` — page structure and content
- `styles.css` — styling, responsive layout, dark/light themes
- `script.js` — theme toggle, smooth scroll, footer year
- `resume.pdf` — drop your resume PDF here so the "Download resume" button works

## Editing
Open `index.html` and replace the marked placeholder text:
- Hero tagline + email (`mailto:hello@example.com`)
- Social URLs (GitHub, LinkedIn, X, Instagram, YouTube, Twitch)
- About paragraph + interests
- Resume entries (Experience, Education, Skills)
- Projects grid (links, descriptions, tags)

## Deploy
- **GitHub Pages**: push to a repo, enable Pages on `main` (root). Done.
- **Netlify / Vercel / Cloudflare Pages**: drag-drop the folder or connect the repo.
- **Local preview**: `python3 -m http.server` then visit `http://localhost:8000`.
